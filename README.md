# 🎮 tamo-junto-games 🕹️
Rede social para gamers com o objetivo de organizar listas de jogos, registrar progresso, avaliar experiências e interagir com outros jogadores.
O projeto está em fase inicial de desenvolvimento e está servindo como base prática para estudo de Front-End e Back-End.

---

## 🔨 Tecnologias planejadas em um primeito momento 
- Front-End (atual repositorio) >> HTML,CSS
- Expansão futura >> JavaScript, responsividade, integração com API
- Back-End (repositorio separado) >> C#, ASP.NET Web API, DTOs, Rotas, CRUD
- Banco (futuro) >> SQL Server / PostgreSQL
